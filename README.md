# CodeX All-In-One Python Discord Bot

Python `discord.py` bot with moderation, music, AI, media, utility, and API integrations.

## Features
- Slash commands with startup console sync logs
- Matching `.` prefix commands
- Owner-only No Prefix grant/revoke system
- Moderation and server management
- Lavalink V4 music with Spotify resolution
- Groq AI
- TMDB movies/TV
- CoinGecko crypto
- OpenWeather weather
- Giphy/Memer/Ksoft fun and media integrations
- MongoDB persistence

## Configuration
Copy `.env.example` to `.env` and fill in the values. Never commit `.env`.
